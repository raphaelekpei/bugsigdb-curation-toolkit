# BugSigDB field guide

Every field on the Study, Experiment and Signature forms, with the rule to apply. Tags show where each rule comes from:

- **[Policy]**: the Curation Policy or Help pages on bugsigdb.org (policy last revised 2026-09-22)
- **[Form]**: the form definition or property page on bugsigdb.org
- **[Reviewer]**: a convention mentors and maintainers consistently apply in GitHub reviews (2025–2026) that isn't written in the policy. Follow it, and say it's a convention if asked.

## 1. Scope

- **[Policy]** Curate differential abundance between conditions: case vs control, exposed vs unexposed, time 1 vs time 2, high vs low exposure. Any host or environment. Taxa can be bacteria, archaea, fungi or other eukaryotes, and viruses.
- **[Policy]** Don't curate: beta diversity or PCoA results, presence/absence results, metabolomics or pathway analyses, clusters from unsupervised learning, or biomarker differential abundance unrelated to the main condition.
- **[Policy]** Both peer-reviewed papers and preprints are in scope. **[Reviewer]** If a preprint has since been published, curate the published version (with its PMID). If a PMID points at the preprint, request a correction on the BugSigDB issue tracker.
- **[Reviewer]** "We curate all reported significant results." An author's own caveat (e.g. "may be a type 1 error") isn't a reason to skip; add it as a discussion note instead. A figure whose direction or groups can't be determined is not curatable.
- **[Reviewer]** Papers with no significant differential-abundance results are closed as not curatable on the GitHub issue.
- **[Reviewer]** If no taxa survive the authors' FDR correction but the authors present uncorrected p < 0.05 results as their findings, curate those results with **MHT correction: No** (maintainer guidance, issue #990). A non-maintainer mentor deleted such an experiment in #1971 (DocTeedee, 2026-10-26, adjusted p > 0.05); #990 outranks, but flag it as a reviewer risk (mentor-rulings §14; 35092013). If the authors present only the FDR-corrected list, curate only that list.
- **[Reviewer / AI team]** Correlation heatmaps (Spearman or Pearson of taxa against a host variable, with significance marks) **are curatable** as correlation experiments (§4). Co-occurrence or network analyses (taxon vs taxon), functional predictions (PICRUSt, KEGG, COG), and metabolite associations are not.
- **[Skill note]** A count of distinct lower taxa *within* a phylum (e.g. "amount of bacterial class/order/family" per phylum, Control vs case, Mann-Whitney) is a within-phylum richness measure, not the abundance of a named taxon. Don't curate it as the phylum increasing or decreasing; note the exclusion (30332459, S1 File Figure B).
- **[Skill note, open]** Cases curated at confidence 50 that are still awaiting a mentor view:
  - taxon-outcome survival (Cox) associations, curated following precedents 39653411 and 35624429 (41160784)
  - an omnibus ANOVA with no post-hoc marks where the authors state pairwise directions in the Results and Abstract. #1160 says omnibus-only is not curatable; 38424540 curated only the taxa the authors assigned to a pair
  - a post hoc test **named in the Methods but never reported** (e.g. STAMP ANOVA + Tukey-Kramer, with only the omnibus p printed on the figure). There's no pairwise result to cite, so treat it like #1160: screen it as not curatable at 70, and keep a contingency draft of the main contrast for the mentor to decide on (28178310; re-screened 2026-11-01 on the 4000 px PLOS figures: no pairwise marks, and the Abstract's Streptococcus claim is p = 0.314 on Fig 4. The export has 70 'ANOVA,Post-Hoc Pairwise' experiments, but those cite a reported pairwise result)
  - significance stated only in the abstract (30988706)
  - culture-based abundance comparisons (culturomics, MALDI-TOF isolates, no sequencing): no sequencing-type option and no culture-only study in the export (2026-10-25); left out with a note, ask on Zulip (31417292)
  - Methods naming two tests ("Analysis of variance and Kruskal-Wallis H test") without saying which one produced the boxplot asterisks. #1190/#842 cover an unstated test, not a choice between two named ones. 41174559 curated Kruskall-Wallis (non-parametric, skewed abundances) at 50 with a note
  - **Mantel test networks** (linkET-style: one taxon per node, edges to clinical variables coloured by Mantel's p, width by Mantel's r), even when the Methods say Pearson and the text calls it a positive association. A Mantel r compares distance matrices and gives no per-taxon abundance direction, and there is no Mantel option in the test dropdown. Left out at 50 with a contingency draft and a Zulip question (40615853, Fig 2D; no ruling for "Mantel")
  - **XGBoost/SHAP beeswarm plots** with no significance test (42857727 Fig 4B, Supplementary Fig 3): left out with a note. Most taxa have almost no high-value (red) points, so the SHAP colours don't give a readable direction (#1124, #820), and #898 asks for direction from an abundance plot, not importance. "Decision Trees (xgBoost, gradient boosting)" exists in the test dropdown but has 0 experiments in the export (2026-11-02)
  Flag each one and suggest a Zulip question.
- **[Skill note]** If the Abstract or Discussion claims differences, but the Results say "no significant differences" and the figure (e.g. a bubble plot) carries no test, don't curate it. This is stronger than the abstract-only case above, because the paper's own Results contradict the claim. Add a study note (33847206, Fig 5 Bifidobacterium species; #431, #123).
- **[Skill note, not yet mentor-reviewed]** Groups **defined by a taxon's own abundance** (e.g. "Lactobacillus dominant" = ≥ 50% *Lactobacillus* vs non-dominant) make that taxon's difference true by definition. Don't curate the defining taxon for that contrast; other taxa compared between such groups are still curatable if significant. Note the exclusion (35092013, Results 3.4; no ruling found).
- **[Form]** Never type "Not reported", "NA", "N/A", "unknown" or "none" into a field. Leave it **blank**. (MHT is "No" when there's no evidence of correction.)

## 3. Study design decision rules  [Policy: Help:Study Design]

| Design | Choose it when… | Not to be confused with |
|---|---|---|
| **case-control** | Participants were **selected because** they have or don't have the outcome or exposure (patients vs healthy controls). Nested case-control within a cohort also counts. | Cross-sectional, where people weren't selected on the outcome |
| **cross-sectional observational, not case-control** | Individuals compared at one time point on an exposure or trait, **without** being recruited on it (e.g. pack-years across everyone, or comparing by race, income, town, or hospital). Also used for correlation of a trait across a general sample. | Case-control |
| **randomized controlled trial** | Researchers **randomly assigned** the treatment (drug, diet, probiotic, placebo). Being in a clinic isn't the defining feature; randomization is. | Non-randomized interventions in humans, which are usually time series or longitudinal |
| **laboratory experiment** | The researcher controls the contrast under lab conditions. Usually animals (mice, rats, pigs, zebrafish, insects including lab-reared mosquitoes) or in vitro. | — |
| **time series / longitudinal observational** | Repeated samples **from the same individuals** over time: before vs after an event, or several timepoints. | Prospective cohort |
| **prospective cohort** | A cohort recruited on a common characteristic and **followed forward**. The comparison is between those who did and didn't develop the outcome. | Time series, which compares within the same person over time |
| **meta-analysis** | Pools data or results from **published literature or public datasets**. Pooling the authors' own two datasets doesn't count. | — |

- **[Policy]** Pick the design that *best* describes the study. **[Reviewer]** Select more than one only when distinct designs coexist in the paper (e.g. a mouse experiment plus a human RCT, or an RCT whose analysis also compares timepoints, in which case add the RCT design).
- **[Reviewer]** "A clear comparison between a disease and a non-disease group" is case-control.

## 4. Defining experiments

**[Policy]** An experiment is one comparison between two groups on which differential-abundance analysis of taxa was done. Most papers have several.

Make a **separate experiment** for each:
- different pair of groups (every pairwise comparison in a multi-group figure, e.g. CF vs healthy, NCFB vs healthy, CF vs NCFB)
- different **body site** (sputum and nasopharynx are two experiments, and each experiment has one body site)
- different **timepoint** comparison (Day 4 and Day 14 are separate; baseline vs post is a different experiment from onset vs post)
- **stratum** or subgroup reported separately (females and males, each disease subtype)
- different test whose significant taxa **don't fully overlap** with another test on the same contrast

**Combine into one experiment** (and list every source):
- figures and tables for the **same contrast and same test** (e.g. a LEfSe cladogram plus an LDA bar plot plus a supplementary table)
- the same contrast reported at different taxonomic levels in different figures or tables (one at species, one at genus)
- **[Policy]** two tests whose significant taxa **fully overlap**: one experiment that lists both tests
- **[Policy]** multiple presentations of the same contrast whose results largely agree. If they differ a lot, keep them separate.

Other rules:
- **[Reviewer]** No significant taxa means no experiment. Delete experiments for contrasts where the paper found nothing.
- **[Reviewer]** Correlation analyses (Spearman or Pearson, or regression on a continuous variable): **current mentor-preferred naming is Group 0 "Low <variable>" / Group 1 "High <variable>"** (209 vs 76 in 2026 curations; TheTosin #1054/#1151, DocTeedee #1154, annemarie-sharp #884). The older "Negative correlation with <variable>" / "Positive correlation with <variable>" is still accepted (328 experiments overall). Be consistent within a study. Sample sizes stay blank and alpha diversity stays blank. Positively correlated taxa go in Signature 1 (increased) and negatively correlated taxa in Signature 2 (decreased). Evidence for blank sample sizes: 289 of 292 correlation experiments leave them blank, including all 73 curated in 2026 (export 2026-10-21). Official mentor ruling: TheTosin, #741 (May 2025), for Spearman correlation experiments: "The matched on factors, sample sizes, LDA score, alpha diversity should be blank" and "Please leave the sample sizes for Experiment 4-9 blank. It's currently curated as 6 each" (the study then passed final review). Experienced reviewers say the same (#1027: "I believe Experiment 4 sample sizes should be left blank"; #1449: "Leave sample sizes and alpha diversity results blank"), and the continuous-regression experiments in #1013 (study 40796247, n = 508) were all left blank. Official mentors per #1274: SvetlanaUP, lwaldron, cmirzayi, jwokaty, annemarie-sharp, Buraah, TheTosin, DocTeedee. Don't call other reviewers "mentors". Record the analysis n in the notes instead. **Correlations with a drug dose are eligible**, because the policy lists drugs and medical treatments as conditions. BugSigDB has 24 dose correlations, all dietary ("… mg/day", Spearman) and none yet for a drug, so mention that in the review request.
- **[Reviewer]** Multivariable models (e.g. a logistic regression predicting case status from several taxa plus covariates): curate taxa with significant coefficients. A positive coefficient for case status goes in Signature 1 (increased) and a negative one in Signature 2 (decreased). Use the model's analytic n, and list its covariates as confounders.
- **[Verified on a real review]** In R tables, rows like `Taxon:RA` / `Taxon: Control` from models of the form `y ~ covariates + microbe:Group` (no main effect) are **group-specific slopes**: the association *within* that group, i.e. a stratified result, not an interaction contrast. Use the group label in the table, **not the paper's prose**, to decide which group a result belongs to, and confirm it with the scatter-plot colours (each group has its own colour). Example: PMID 42059388 says RF correlated with *S. anginosus* "within the RA group", but Table S1 labels it `:Control` and the driving point in Fig 5H is a control. If such an experiment is curated, include **every** significant taxon for that group from the table, not just the one the text highlights.
- **[Judgment, ask Zulip]** Taxa associated with host biomarkers or immune markers (cytokines, antibody titres, CRP) are only curatable when the biomarker is a meaningful condition, e.g. an RA autoantibody. Interaction models stratified by group are especially ambiguous. Draft them as optional and flag them rather than adding them silently.
  - **[Skill note, not yet mentor-reviewed]** When cytokines or CRP are the paper's **primary outcome** (e.g. a population cohort regressing 45 cytokines on species abundance), they're the study's question rather than a side marker. Curate one Low/High experiment per marker that has significant taxa, using the marker's own glossary term (`controlled-vocabularies.md`). Reviewed precedents: 36059521 and 39103909, one experiment per cytokine; clinical markers are covered by #1151 and #1154 (40859402).
- **[Reviewer]** Paired within-person before/after comparisons (e.g. pre vs post HSCT) are *pre vs post* experiments for each participant group, not pairwise comparisons between groups.
- **[Skill note, not yet mentor-reviewed]** **Between-group change scores** (e.g. a mixed model on log(post/pre) abundance, cases vs controls): one experiment with the two groups as Group 0 / Group 1, the direction of the change in Group 1 relative to Group 0, and the change described in the signature description. Precedent 38424099 Exp 2 ("Placebo (change between baseline and study end)" vs "Prebiotic"; reviewer Chloe = cmirzayi), whose study keeps only its base design (randomized controlled trial): so a nested case-control change-score study stays case-control, without adding time series (#753 is for within-person contrasts). Alpha diversity uses the matching change test (e.g. Shannon change cases vs controls). Adjustment for the baseline value of the outcome ("controlling for the pre-exposure relative abundance") goes in confounders under #442 (variables the DA model was adjusted for), worded as the paper gives it (#1141), at 70; no ruling or export precedent for that specific variable (SMW `Confounders controlled for::~*baseline*` = 0, 2026-11-01). Leave Group 1 definitions free of the experiment ("…was compared with controls"; #469, #542) (34537015, re-check 2026-11-01).
- **[Skill note, not yet mentor-reviewed]** **Sample-site contrasts in the same people** (tissue biopsy vs fluid, stool vs biopsy, saliva vs vagina): Condition **"Sampling site"** (30 experiments / 14 studies; "Specimen" 7). Body site lists **both** sites (24 of 30, including SvetlanaUP-reviewed 37419941 "Feces, Duodenum", 38171017 "Vagina, Saliva", 38528960); the one-site rule (#477, #1197) is for condition contrasts within a site. No rule fixes which site is Group 0 (27884202: biopsy 0, lavage 1; 37419941: stool 0, biopsy 1). Pick the reference sample the paper frames as standard and say why. Human studies are mostly cross-sectional (13 of 15). Paired samples aren't "Matched on" (35092013). When both sites map to the **same** UBERON term (two sub-sites of one organ), enter that one term: SvetlanaUP-reviewed 32719372 (Cervicovaginal vs Introitus → "Vagina"); 26600277 (skin above vs below the panniculus → "Skin of abdomen"; UBERON has no fold or intertriginous term). A self-described "prospective cohort" sampled once, with no outcome followed, is still cross-sectional here (#70, #118; 26600277).
- **[Policy]** "Duplicate this experiment" copies the shared fields. Use it, then change only what differs.
- **[Reviewer]** Experiment and signature numbers can't be renumbered, and gaps after deletions are fine.

## 5. Experiment fields: subjects and contrast

| Field | Rule |
|---|---|
| **Location of subjects** | **[Policy]** The country where subjects were recruited, or where samples were collected for animal or environmental studies. Look up a city or hospital to find the country, and look at the ethics committee name (e.g. "GDIRB" → Guangzhou → China). Multiple countries are allowed (meta-analyses). If no location is given, use the affiliation country of the first and last authors. |
| **Host species** | **[Policy]** The species sampled, chosen from the dropdown. Leave it as "Not specified" for environmental studies. Ask on Zulip to add a missing host. **[Skill note]** Don't substitute a related species (no *Equus caballus* for a donkey, 33499942). While you wait, a higher taxon that's in the dropdown is acceptable with a note ("Aves" for the crested ibis, 2 precedents incl. 41209719; 33891612). Humans are *Homo sapiens*, mice *Mus musculus*, rats *Rattus norvegicus*, dogs *Canis lupus familiaris*. |
| **Body site** | **[Policy]** A UBERON anatomical term, chosen from the glossary autocomplete. **[Form]** Enter it the way the form's autocomplete shows the glossary term, which has a capital first letter (e.g. "Vagina", "Feces", "Rheumatoid arthritis"): BugSigDB stores "Vagina" in 256 experiments and never "vagina" (export 2026-10-21). Select the suggestion rather than free-typing. **[Reviewer]** Use **one** body site per experiment, and the most specific one the samples came from: stool → *feces*, vaginal swab → *vagina*, plaque from tooth surfaces → *dental plaque* (not oral cavity), *tongue* (not "dorsum of tongue" when tongue is the glossary term). Sites have synonyms (mouth / oral cavity). If samples are feces even though the study is "about" milk, the body site is feces. |
| **Condition** | **[Policy]** The disease, treatment, drug, exposure, trait or variant that **this experiment contrasts on**, chosen from EFO. Never "microbiome measurement". Glossary term as autocomplete shows it (capital first letter, e.g. \"Rheumatoid arthritis\"). **[Reviewer]** Curate the experiment's condition, not the whole study's: if Group 1 is healthy pregnant women, "gestational diabetes" is wrong. For a lab-measured trait use the EFO measurement term (e.g. "high density lipoprotein cholesterol measurement"). Let Group 1's name guide you. Look at how earlier BugSigDB studies on the same topic coded it. Keep it minimal, e.g. just "COVID-19" rather than also adding "intestinal disease". **[Precedent + peer review]** For drugs, match the term to what the contrast is. **Treated vs untreated, or treatment response:** use "Response to <drug>" (BugSigDB precedent: "Response to antiviral drug" 42, "Response to anti-tuberculosis drug" 31, "Response to drug" 10). **Correlation with a drug dose:** use "<drug> dose measurement" if the glossary has it (e.g. "Methadone dose measurement"), otherwise the drug's own term (e.g. "Methotrexate"). If neither can be selected in the form (see "When a glossary term won't autocomplete" in `controlled-vocabularies.md`), keep the closest selectable term and say so in the review reply. In PMID 42059388, the reviewer accepted "Response to methotrexate" on that basis. "Response to methotrexate" was rejected in peer review for a dose correlation, because dose isn't treatment response. **[Maintainer, #1965]** EFO terms can't be edited. If the exact concept isn't in the selector, search related wordings (e.g. for parity: parity, number of live births, gravidity, pregnancy, reproductive history), then fall back to the **nearest parent term** (e.g. "pregnancy"). Never choose a term for a *different* concept (e.g. "breastfeeding duration" when the variable is feeding mode). |
| **Group 0 name** | **[Policy]** The control, unexposed, or reference group. **[Help:Contrast]** For severity, Group 0 is the low or mild group. **[Reviewer]** For timepoints, Group 0 is the earlier one. |
| **Group 1 name** | **[Policy]** The case or exposed group (higher severity, later timepoint, treatment). **[Reviewer]** Start with a capital letter. Spell out abbreviations once ("Colorectal cancer (CRC)", "Human immunodeficiency virus positive (HIV+) injectors"). Keep the paper's own group labels when they help, e.g. "Healthy control (ctrl)", "Distinct Sarcopenia (G1)". Don't wrap the whole name in parentheses. Check spelling (reviewers catch "Thalassemia"). Use grammatical forms ("pre-diabetes", not "pre-diabetics"). Use the paper's own wording and number for group names: e.g. "Healthy controls" when the paper says "healthy controls" (the most common BugSigDB form: 770 plural vs 259 singular, with only the first letter capitalized). Only add an abbreviation like "(HC)" if the paper uses it. |
| **Group 1 definition** | **[Form]** The diagnostic or inclusion criteria that define Group 1, written as a full sentence with abbreviations expanded (e.g. "Patients with non-alcoholic steatohepatitis (NASH) diagnosed by …"). **[Reviewer]** Every abbreviation in the definition is written in full with the abbreviation in brackets straight after ("maternal vulnerability (MV)", "postnatal day 2 (PND2)"), never "(maternal vulnerability model, MV)" (#295, #926, #1050; peer request on 31971855). `check_curation.py` warns on any upper-case token never spelled out in the experiment and on the comma form; cohort, kit, strain and gene names, units and staging codes are allowed. For a paper's own labels that aren't abbreviations (herd codes "RN"/"VL" in 40369688), add `"abbreviations_ok": {"RN": "<reason>"}` to the study object. Paraphrase the paper's definition precisely and don't invent criteria. |
| **Group 0 / Group 1 sample size** | **[Help:Contrast]** The **final analytic** sample size for this experiment, not the number screened or enrolled. Never swap them. **[Reviewer]** Leave a size blank when it isn't reported, which is common in mouse studies, or when the stated n belongs to different groups. Count fecal samples when the experiment is on feces. |
| **Antibiotics exclusion** | **[Policy]** Only the antibiotics criterion, formatted "X <unit>" ("2 months", "6 weeks", "28 days"). Use "currently on antibiotics" for active use or current treatment. Don't include non-antibiotic exclusions. **[Reviewer]** Use a space between number and unit ("3 months", not "3months"). Mentors convert whole-month week counts to months (4 weeks → "1 month", 8 weeks → "2 months"). "Recent antibiotic use" isn't the same as current use, so curate it as reported. When the paper says only "recently used antibiotics" with no window, enter the ruling's own phrase "Recent antibiotic use" (SvetlanaUP #1381) rather than a paraphrase such as "recently used antibiotics", which no BugSigDB experiment uses (skill note, PMID 40304477; not yet mentor-reviewed). Leave it blank when no antibiotics criterion is stated, which includes lab animals. A non-window criterion can be quoted briefly (e.g. "antibiotic exposure since birth until the end of the study"). Don't add notes. |

## 6. Experiment fields: lab analysis  [Policy]

| Field | Rule |
|---|---|
| **Sequencing type** | 16S, 18S, WMS (shotgun / whole metagenome), ITS / ITS2, PCR (including qPCR and RT-qPCR), RNA-Seq. **[Reviewer]** Use what was used for the *taxonomic* profiling, not gene-specific RT-qPCR of host genes. |
| **16S variable region** | Lower bound is required. Upper bound is filled only for a range (V3–V4 → 3 and 4). A single region (V4) goes in the lower bound only, with the upper bound blank. Leave it blank if not reported. |
| **Sequencing platform** | Choose from the dropdown. MiSeq, HiSeq, NovaSeq, and NextSeq → Illumina. Ion PGM or S5 → Ion Torrent. MinION or GridION → Nanopore. **[Reviewer]** If the platform is truly not stated, leave it blank rather than guessing. Inferring it from a clearly named instrument or sequencing provider is fine and earns credit. |

## 7. Experiment fields: statistical analysis

| Field | Rule |
|---|---|
| **Data transformation** | **[Policy]** The transformation applied right before or within the DA test. Relative abundances is the default and most common. Raw counts go with DESeq2, edgeR, negative binomial, or Poisson. Centered log-ratio goes with ALDEx2, CLR-then-linear-model, and some ANCOM/corncob setups. Arcsine square-root and log transformation are rare. |
| **Statistical test** | **[Policy]** The test used *for differential abundance*, chosen from the dropdown. Several can apply (especially multi-group: e.g. Kruskall-Wallis + Dunn's test, or ANOVA + Post-Hoc Pairwise). **[Reviewer]** Don't list tests used only for diversity or clinical variables. Wilcoxon signed-rank and rank-sum → "Mann-Whitney (Wilcoxon)". ANCOM-BC2 and MaAsLin2/3 are separate options. If the test isn't stated and the figure clearly implies one, curate the implied test **and** add a discussion-page note explaining the choice. If the test isn't in the dropdown (e.g. LinDA, Maaslin variants, Cliff's delta), ask on Zulip or a BugSigDB GitHub issue to have it added, rather than substituting a different test. |
| **Significance threshold** | **[Policy]** A single number only ("0.05", "0.01", "0.001"). **[Reviewer]** Use the threshold that applies to *this* DA test. In LEfSe the Kruskal-Wallis alpha is often 0.01 even if "p < 0.05" applies elsewhere. With FDR or MHT, use the FDR cutoff (20% FDR → "0.2"). If none is stated, use 0.05. |
| **MHT correction** | **[Policy]** Yes, No, or blank. "No" when there's no evidence of correction. Blank only when no traditional significance test was used (Bayesian, effect-size cutoff). It's Yes when the paper says Bonferroni, FDR, Benjamini-Hochberg, q-value, or "adjusted p". DESeq2 corrects by default, LEfSe doesn't. **ANCOM in QIIME2** (`qiime composition ancom`, verified for q2-composition 2023.5 / scikit-bio 0.5.7) applies Holm–Bonferroni to each taxon's log-ratio p-values before counting W, and users can't turn it off, so ANCOM run in QIIME2 is MHT **Yes**. ANCOM-BC reports q-values, so it's Yes when the paper uses q. **"Adjusted P-values" in a regression paper usually means covariate-adjusted, not multiple-testing corrected.** Only count it as MHT when the paper names a correction (FDR, BH, Bonferroni, q-value), or when the authors' code applies one (`p.adjust`, `qvalue`, etc.). When a tool's default decides the answer, check the authors' code repository (Data Availability section) and the tool's source code for the version they used. When the paper reports both corrected and uncorrected lists, curate the corrected list. |
| **LDA score above** | **[Policy]** LEfSe only, and numeric only, with no ">" or "≥". If an LDA cutoff is used but its value isn't given, enter **2**. If no LDA cutoff is mentioned, leave it blank. **[Reviewer]** Enter "2", not "2.0". Log-LDA > 2 is entered as 2. |
| **Matched on** | **[Policy]** Only when controls were *selected* to match cases on characteristics, usually in a case-control design. Look for the word "match" in the paper. Propensity-score matching counts. Use full dropdown terms ("body mass index", not "BMI"). **[Reviewer]** Matching applies only to the matched contrast, e.g. not to "mild vs severe cases" if matching was case vs control. "Age- and sex-matched" is not the same as adjusted, which belongs under confounders. Use "sex" instead of "gender". Leave it blank if there was no matching. |
| **Confounders controlled for** | **[Policy]** Only variables (other than the contrast) accounted for **in the DA analysis**, by (1) stratification, reporting results separately per stratum, or (2) adjustment, including covariates in a regression or mixed model (MaAsLin, GLM, negative binomial, etc.). Bivariate tests (t-test, Mann-Whitney/Wilcoxon, Kruskal-Wallis, LEfSe, chi-square, Fisher) **cannot** adjust. **[Reviewer]** Confounders used only for other analyses don't count. Use synonyms from the vocabulary to avoid yellow flags, but don't swap in terms with a different meaning. |

## 8. Alpha diversity  [Policy + Reviewer]

- Fields: Pielou, Shannon, Chao1, Simpson, Inverse Simpson, Richness, Faith.
- **Increased** if Group 1 is significantly higher, **decreased** if significantly lower, **unchanged** if tested and not significant, and **blank** if that index wasn't tested for this contrast.
- **[Reviewer]** This is a frequent deduction. Fill only the indices the paper actually reports for *this* contrast. Don't mark untested indices "unchanged", and don't copy alpha diversity to experiments for other contrasts (e.g. severity subgroups, correlation experiments). If the paper says alpha diversity was tested but shows no results, leave it blank.
- **[Reviewer]** Mapping: observed OTUs, ASVs, features, or species, and ACE → Richness. MGWAS 'gene count' (genes detected per sample) → Richness, as in the mentor-reviewed study 26408641 and 25758642 (skill note, 28873967). Evenness → Pielou. Make sure Simpson and Inverse Simpson aren't confused. If rank-specific alpha diversity is reported (e.g. significant at class level only), it applies to the experiment at the matching rank. Add a discussion note quoting the paper when it's subtle.
- **[Skill note]** Read what each index means in this paper before setting the direction. "Simpson" can be the Gini-Simpson diversity (higher = more diverse; 41157277) or mothur's dominance index (higher = less diverse; 36082082). Record the direction the paper reports for its index and say which variant it is in a note. Heip's evenness → Pielou is a judgment call (41029586). An unnamed "species diversity" index can be identified from its value range (≈6 fits log2 Shannon, <1 fits Simpson, hundreds fit Chao1/observed; 32504527), with a note. When the paper's formula and its wording disagree, use the values: in Lactobacillus-dominated vaginal samples Gini-Simpson sits near 0 and dominance D near 1, so a control group clustered near 0 means the plot is Gini-Simpson (35513786: formula 1−ΣPi² but text says 'lower = more diverse'; Fig 1A negatives median ≈0.12). ## 9. Signature fields

| Field | Rule |
|---|---|
| **Source** | **[Policy]** The figure or table number(s) where the signature appears. **[Reviewer]** Be exact: "Figure 2B", "Table S5", "Figure 4A, Supplementary Table 2", "S2 Table in S2 Text". For text-only results use `Text; RESULTS: <exact section heading>`, with no page numbers. If taxa appear partly in text and partly in a figure, list both. "Results section" alone isn't acceptable. Don't cite a descriptive table that has no statistics. **[Peer review]** Cite only figures and tables that **show the taxa and their direction**. A model-performance figure (ROC/AUC curve, variable-importance plot without directions) is not a source, even if the text cites it next to the model. Cite the table with the coefficients instead (e.g. "Table S1"). |
| **Description** | **[Reviewer]** A short plain sentence describing the result, with abbreviations expanded on first use (e.g. "Linear discriminant analysis effect size (LEfSe) results between No/mild oral mucositis (Muc0-1) and Moderate oral mucositis (Muc2) groups"). Don't prefix it with "Description:". If one signature combines taxonomic levels, say so (e.g. "phylum, family and genus level"). |
| **Abundance in Group 1** | **[Policy]** increased or decreased. Use one signature per direction, so an experiment has 1 or 2 signatures. **[Reviewer]** Never put both directions in one signature or make two signatures for the same direction. If a LEfSe plot's colors are Group 0 = red and Group 1 = green, then green taxa → increased and red taxa → decreased. Re-read the legend every time. |
| **NCBI (taxa)** | See `taxonomy.md`. **[Policy]** Curate every significant taxon at every rank reported, and enter only the lowest rank the paper gives for that taxon. **[Reviewer]** The taxon count must match the figure or table exactly. All taxa shown in a LEfSe cladogram or LDA histogram are significant, and none should be left out. Curate only taxa marked significant (asterisks, highlighted rows, adjusted p below threshold). |
| **Bulk entry** | **[Policy]** Paste comma-separated integer NCBI IDs into the NCBI field, then check that the last one autocompleted (press space or delete a trailing space). |
